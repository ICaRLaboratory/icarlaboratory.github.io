# 세종대학교 교표

- 공식 UI 안내: https://www.sejong.ac.kr/kor/intro/ui-guide.do
- 공식 원본 묶음: `Basic_Element_ai_v3.zip`
- 다운로드: https://www.sejong.ac.kr/cms/etcResourceDown.do?site=%24cms%24NYewTkA&key=%24cms%24EIQwzglgxg+gogGwKYFskDsAuMQRgNwGYA6ALwgAcg
- `sejong-symbol.png`: `1-1.교표.ai`의 교표 도형을 RGB PNG로 렌더링했습니다. 원 바깥으로 연결된 흰색 배경만 투명하게 처리하고, 원 내부의 흰색과 교표의 색상·비율은 유지했습니다.

## 적용 원칙

- 홈의 학교명 앞에 단독 교표를 사용하며, 푸터에는 학교 로고를 넣지 않습니다.
- 흰색 사각형이나 외부 패딩을 붙이지 않습니다. 교표 원 내부만 흰색을 유지합니다.
- 색 반전, 흰색 단색화, CSS 색상 필터를 적용하지 않습니다.
- `1-8.색상규정1.ai`, `1-8.색상규정2.ai`를 참고합니다. 기본 색상 규정에는 Sejong Crimson Red(RGB 195, 0, 47)와 Sejong Gray(RGB 81, 98, 111)가 지정되어 있습니다. 배포 이미지는 AI 원본 색상을 렌더러로 RGB 변환한 것이며 임의로 재채색하지 않았습니다.
- 시그니처를 다시 사용할 경우 `1-3.프라이머리 시그니춰_가이드.ai`, `1-5.시그니춰 조합_국영문_가이드.ai`의 비례·간격 변경 금지 규정을 따릅니다.

세종대학교 소속 표시에 사용합니다. 로고의 권리는 세종대학교에 있으며, 사이트 코드의 재사용 허가에 포함되지 않습니다.
