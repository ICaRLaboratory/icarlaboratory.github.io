# 지능제어 및 로보틱스 연구실 사이트 디자인 기준

이 문서는 현재 승인된 홈페이지의 시각·언어 기준을 정리한 유지보수 지침입니다. 새 템플릿이나 다른 사이트용 테마가 아니며, 기계 처리용 Google DESIGN.md 규격도 아닙니다.

## 기준 파일과 변경 범위

- 공통 디자인 구현: `assets/style.css`. 색상·폰트·여백 토큰은 `:root`, 검은 영역의 반전 값은 `.invert`에 있습니다.
- 논문 페이지 전용 디자인: `assets/publications.css`.
- 공통 HTML 생성: `assets/site.js`. 연구실·구성원·강의·논문 사실 정보는 `data/`가 기준입니다.
- 검증 목록과 실행 방법: `tests/README.md`.
- 사용자의 최신 승인 범위가 우선합니다. 한 요소의 수정 승인을 다른 페이지의 재설계로 확대하지 않습니다. 기준을 바꾸면 구현·문서·해당 검증을 함께 갱신합니다.

## 색상과 구조

- 흰 본문과 검은 내비게이션·홈 상단·푸터를 유지합니다. 기본 강조색은 검정이며 `.invert` 안에서 밝은색으로 반전합니다.
- 본문은 `--text`, 보조 설명은 `--dim`, 더 낮은 강조는 `--faint`를 사용합니다. 연한 색이라는 이유만으로 색 대비 검증을 생략하지 않습니다.
- 본문 폭은 `--maxw`, 좌우 여백은 `--pad`, 구역 간격은 `.band` 계열을 따릅니다. 특정 화면을 맞추려고 공통 폭이나 여백을 임의로 바꾸지 않습니다.
- 세종대학교 로고는 원본 색과 비율을 보존합니다. Contact 지도 서비스의 브랜드색은 승인된 예외입니다.

## 글자의 역할

| 역할 | 적용 기준 |
|---|---|
| 본문·제목 | Pretendard 기반 `--sans` / `--display`. 제목은 `.display`, `.h2`, `.h3`의 공통 크기·굵기 사용 |
| 구역 표제 | `.eyebrow`: 본문 계열 1rem, 600. 기존 영문 대문자 처리 유지 |
| 일반 정보성 태그 | `.tag`: 본문 계열 .85rem, 500, 정상 자간 |
| 강의 연도·과제 상태 | `--info-size: .85rem`, `--info-weight: 500`, `--sans`, 줄높이 1.5, 정상 자간 |
| 학부·대학원 구분 | `.course__level`: 본문 계열 .9rem. 선택 언어만 표시 |
| Contact/Members 연락처 라벨 | 본문 계열 .8125rem, 600, 정상 자간. ORCID/Scholar에도 같은 규칙 적용 |
| 장식·기술 표기 | 기존 고정폭 숫자·도표·시뮬레이터 표기는 별도 역할. 위 정보성 글자 규칙을 이유로 일괄 변경하지 않음 |

강의 연도와 과제 상태는 읽어야 하는 정보이므로 작은 고정폭·넓은 자간 조합으로 되돌리지 않습니다. 강의 연도는 `tabular-nums`로 숫자 정렬을 유지합니다. 과제 상태의 영문 대문자와 진행 중/완료 색 구분, 배지 외곽선·둥근 모양은 보존합니다. 글자 확대 시 높이를 고정하지 않습니다.

## 버튼·배지의 구분과 예외

- 링크는 이동, 버튼은 동작, 상태 배지는 정보 표시입니다. 상태 배지를 클릭 가능한 컨트롤처럼 만들지 않습니다.
- Research/Members 구역 링크와 Gallery 연도 필터는 본문 계열 글꼴과 기존 얇은 외곽선을 사용합니다. 탐색 링크를 선택 탭처럼 바꾸지 않습니다.
- 기존 내부 링크 화살표는 →, 외부·이메일 목적지는 ↗입니다. 홈 상단의 연구 분야·구성원 이동 버튼은 동일한 오른쪽 화살표를 사용합니다. 일반 탐색 링크와 방향 제어에는 일괄 추가하지 않습니다.
- 일반 탐색 타깃과 달리 Contact 링크의 기본 38px 높이, CV의 기본 28px 높이, 본문 내 뉴스 링크의 작은 크기는 승인된 예외입니다. 전부 44px로 강제 통일하지 않습니다. 확대 글자에서는 내용에 맞게 커져야 합니다.
- 키보드 초점 표시를 유지하며, 보이지 않는 메뉴 항목은 Tab 순서에서 제외합니다.

## 문구·언어·사실 정보

- 메뉴와 페이지의 큰 제목은 기존 영문 정책을 유지하고, 번역 대상으로 정한 본문·정보는 선택 언어만 표시합니다. 페이지별 명시적 바인딩이 기준이며 일괄 번역하지 않습니다.
- Teaching은 표기명이며 주소는 `lecture.html`, 큰 제목은 `Courses taught.`입니다.
- 홈 논문 영역은 `Publications` / `Recent publications`, 연구과제 제목은 `Research projects.`입니다.
- 시뮬레이터 설명은 조건·제어 동작·평가 지표를 직접 기술합니다. 문체 수정으로 제어식·파라미터·가정·수치 결과를 바꾸지 않습니다.
- 제어 알고리즘·로보틱스·임베디드 시스템은 독립된 연구 분야입니다. 연구 내용은 별도 승인 없이 수정하지 않습니다.
- 공식 명칭과 논문 서지 표기는 공식 자료를 따릅니다. 출판사가 쓰지 않은 `p.`, `no.`, `Art. no.`를 선호 양식이라는 이유로 추가하지 않습니다.

## 검증 연결

- `tests/info-typography-interactions.mjs`: 강의 연도·과제 상태의 본문 글꼴, 크기, 굵기, 자간, 내용 보존, 언어 전환, 320/390/768/1280px 및 확대 글자 배치.
- `tests/language-interactions.mjs`: Teaching 표기, 과목명·학부/대학원·연도의 선택 언어와 데이터 일치.
- `tests/enlarged-layout-interactions.mjs`: 실제 브라우저 기본 글자 설정에서 강의명·연도 겹침과 줄바꿈. CSS 글자 확대 실험과 구분합니다.
- `tests/accessibility-interactions.mjs`: 실제 배경에서의 색 대비 및 인쇄 표시.
- 버튼·구역 링크·CV 예외는 `tests/README.md`의 해당 상호작용 검사에서 확인합니다.

테스트 통과는 가독성과 디자인 판단의 전부가 아닙니다. 수정 요소를 실제 화면에서도 보고, 한글·영문·모바일에서 의미와 정보 위계가 유지되는지 확인합니다.
