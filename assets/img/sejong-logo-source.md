- 공식 원본 묶음: `Basic_Element_ai_v3.zip`

- `sejong-symbol.png`: `1-1.교표.ai`의 교표 도형을 추출해 흰색 배경의 RGB PNG로 렌더링했습니다.
- `sejong-wordmark.png`: `1-5.시그니춰 조합_국영문.ai`의 가로형 조합을 통째로 추출해 흰색 배경의 RGB PNG로 렌더링했습니다.

## 적용 원칙

- `1-3.프라이머리 시그니춰_가이드.ai`와 `1-5.시그니춰 조합_국영문_가이드.ai`의 비례·간격 변경 금지 규정을 따릅니다. 교표와 글자를 따로 재조합하거나 늘이지 않고, 원본 조합 전체를 같은 비율로 축소합니다.
- `1-8.색상규정1.ai`, `1-8.색상규정2.ai`를 참고합니다. 기본 색상 규정에는 Sejong Crimson Red(RGB 195, 0, 47)와 Sejong Gray(RGB 81, 98, 111)가 지정되어 있습니다. 배포 이미지는 AI에 포함된 원본 색상을 렌더러로 RGB 변환한 것이며 임의로 재채색하지 않았습니다.
- 색 반전, 흰색 단색화, CSS 색상 필터를 적용하지 않습니다. 어두운 사이트 배경에서는 로고 뒤에 흰색 면과 외부 여백을 둡니다. 외부 패딩은 사이트 배치용이며, 가이드에 없는 최소 여백 수치라고 주장하지 않습니다.
- 종전 공식 홈페이지 푸터에서 가져온 흰색 이미지와 그 심벌 크롭은 사용하지 않습니다.

세종대학교 소속 표시에 사용합니다. 로고의 권리는 세종대학교에 있으며, 사이트 코드의 재사용 허가에 포함되지 않습니다.
